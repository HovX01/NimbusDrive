Overview

Nimbus is your self-hosted backend. Telegram stores file bytes. SQLite stores metadata and app data. Your apps call one HTTP API.

APIPurposeBackend
StorageUpload, import, download filesTelegram
DataCRUD + query collectionsSQLite
DriveFolders, trash, searchSQLite + Telegram

Authentication

API key (for your apps)

X-Nimbus-Key: <key from data/api.key>

# or
Authorization: Bearer <key>

Use for Storage API, Data API, and file operations.

Access key (optional)

When NIMBUS_PUBLIC=false, also send:

X-Nimbus-Access: <key from data/access.secret>

JWT (web UI)

Telegram login → Authorization: Bearer <jwt> for UI session endpoints.

Storage API

POST /api/v1/files/upload

Multipart upload. Returns url when using API key.

curl -X POST http://localhost:9090/api/v1/files/upload \
  -H "X-Nimbus-Key: YOUR_KEY" \
  -F "file=@photo.jpg" \
  -F "parent_id=root"

POST /api/v1/files/import

Import any HTTPS file URL.

curl -X POST http://localhost:9090/api/v1/files/import \
  -H "X-Nimbus-Key: YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com/photo.jpg"}'

GET /api/v1/files/{id}/download

Download file bytes. Supports Range header.

GET /api/v1/share/{token}/download

Public download — no API key. Use in <img src>.

Data API

JSON collections in SQLite — like Supabase tables.

GET /api/v1/data/{collection}

Query with filters:

FilterExample
equals?status=eq.active
greater than?price=gte.10
like?name=like.*shirt*
sort?order=price.desc
page?limit=20&offset=0

POST /api/v1/data/{collection}

curl -X POST http://localhost:9090/api/v1/data/products \
  -H "X-Nimbus-Key: YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name":"Shirt","price":29.99,"image_file_id":"FILE_UUID"}'

PATCH /api/v1/data/{collection}/{id}

Update fields (merged into existing JSON).

DELETE /api/v1/data/{collection}/{id}

Delete row.

GET /api/v1/data/collections

List all collection names.

Full example

Upload image to Telegram, save product in SQLite:

# 1. Upload image
curl -X POST http://localhost:9090/api/v1/files/upload \
  -H "X-Nimbus-Key: YOUR_KEY" -F "file=@shirt.jpg"
# → { "id": "...", "url": "http://.../share/.../download" }

# 2. Create product row
curl -X POST http://localhost:9090/api/v1/data/products \
  -H "X-Nimbus-Key: YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Blue Shirt",
    "price": 29.99,
    "image_file_id": "FILE_ID_FROM_STEP_1",
    "image_url": "URL_FROM_STEP_1"
  }'

# 3. Query
curl "http://localhost:9090/api/v1/data/products?order=created_at.desc" \
  -H "X-Nimbus-Key: YOUR_KEY"
